# Changelog

## 0.1.0 — 2026-10-26

First Linux desktop preview of Astro Studio.

- Explicit local Astro project selection and metadata diagnostics.
- Owned development preview with actual local URL detection, bounded logs, restart, and process-group cleanup.
- Local Markdown/MDX browsing with a documented supported YAML subset.
- Existing title, description, and draft forms with source-preserving, undoable native editor edits.
- Proactive editor/external-file conflict detection with retained form drafts and explicit reload.
- Saved-file refresh and native Source Control/diff handoff.
- Bundled VSIX, clean-profile and Restricted Mode verification, and Linux CI.

Visual component drag-and-drop, agent integrations, media management, deployment, and additional operating systems remain separate milestones.
